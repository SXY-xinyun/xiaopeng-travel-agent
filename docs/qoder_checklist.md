# 开发过程证明清单（Qoder / Cursor）

赛题说明：使用 Qoder/QoderWork 的截图和对话记录可作为**额外加分项**，非强制。

## 建议提交 4–6 张截图

1. **架构讨论**：与 AI 讨论双模式编排 / 安全护栏的对话截图  
2. **代码生成**：生成工具箱或编排引擎的界面截图  
3. **调试过程**：修复疲劳场景误放歌 / 横穿播报拦截的对话  
4. **Demo 联调**：本地或公网打开 Web Demo 的浏览器 + 终端截图  
5. **部署过程**（可选）：轻量服务器 Docker Compose 启动成功截图  
6. **百炼配置**（可选）：Key 配置成功后 `/api/health` 返回 `llm_configured:true`（打码 Key）

## 打包方式

- 放入 `docs/process_screenshots/`（自行创建，勿含密钥）  
- 或插入技术报告附录  
- 论坛帖中附 2–3 张关键图即可  

## 注意

- **打码** API Key、服务器密码、个人账号  
- 保留时间戳或对话标题，证明为本团队完成
