# 作品介绍（STAR）

**标题建议：** Qoder码力星期四·小鹏 AI 出行Agent —— 双模式出行服务编排管家

## S · Situation 场景

智能座舱与 Robotaxi 能力已经具备基础车控、导航、订单能力，但用户一句自然语言背后往往是风险与目标的组合。例如：

- 车主说“有点困，放首歌” → 真实风险是疲劳驾驶
- Robotaxi 乘客说“我跑到马路对面去上车” → 真实风险是穿行事故

痛点：若 Agent 只做指令映射，会错过安全边界与服务闭环。

## T · Task 任务

打造更高层的服务编排 Agent，在已有工具之上完成：

1. 识别车主 / Robotaxi 乘客真实意图与风险等级
2. 组合工具形成可解释服务计划
3. 对高风险动作拒绝、降级或转人工
4. 通过 Web Demo 让评委复现至少 4 类典型场景

成功标准：在疲劳驾驶、亲子出行、危险上车点、乘客求助等场景中，均能输出「回复 + 计划 + 工具链 + 禁止动作 + 安全提示」。

## A · Action 行动

- **架构：** FastAPI + 编排引擎（意图识别 → 安全评估 → 工具规划/执行 → 回复生成）
- **工具箱：** 座舱（空调/座椅/媒体/疲劳辅助）、导航/休息点/超充、Robotaxi 订单/定位/改点/改目的地/舒适辅助/转人工
- **安全规则：** 疲劳禁娱乐主策略、禁止引导横穿、儿童锁与温控、求助必转人工
- **体验：** 深色座舱 HUD Web Demo，可视化风险、计划与工具状态
- **模型：** 阿里云百炼通义千问负责意图理解与工具编排；规则引擎做安全护栏；无 Key 时自动降级规则编排

## R · Result 结果

- 本地一键启动，公开可访问（部署后填写链接）或录制 3–5 分钟 Demo 视频
- 覆盖 8 个推荐标准场景中的核心链路
- 代码可复现，附启动命令与场景测试脚本
