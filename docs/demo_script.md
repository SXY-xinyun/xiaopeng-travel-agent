# Demo 视频脚本（3–5 分钟）

**用途：** 公网链接之外的备份交付；也可与公网链接同时提交。

## 录制前检查

1. 打开体验页，确认右上角显示 **「LLM 已连接」**  
2. 浏览器全屏，字体缩放 100–110%  
3. 准备口播，语速中等

## 分镜（约 4 分钟）

| 时间 | 画面 | 口播要点 |
|---|---|---|
| 0:00–0:25 | 首页品牌 + 健康芯片 | 这是小鹏 AI 出行服务管家，做更高层服务编排，不是普通车控助手 |
| 0:25–0:40 | 点击「自动演示 4 场景」 | 评委剧本：2 车主 + 2 Robotaxi |
| 0:40–1:20 | 疲劳场景结果 | 用户说放歌，Agent 识别疲劳风险，工具链到休息点，禁止娱乐主策略 |
| 1:20–1:55 | 亲子场景 | 不开窗，先锁门+空调，安全边界可视化 |
| 1:55–2:40 | 上车点异常 | 拒绝横穿，改安全落客区，地图示意 + 工具时间线 |
| 2:40–3:25 | 乘客求助 | 舒适辅助 + 安全停车 + 转人工 |
| 3:25–3:50 | 右侧面板总览 | 强调：回复、计划、工具理由、禁止动作、状态对比 |
| 3:50–4:10 | 收尾 | 公网链接 + 代码可复现 + 百炼多轮编排 |
